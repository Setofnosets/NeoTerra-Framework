Neo Terra Framework

World state is stored per chat. These settings are global defaults for new and existing chats.

Narrator card

Director mode uses the bundled Neo Terra — Director card for a neutral narrator voice. Download it, then import it in SillyTavern: Characters → Import character. Solo mode uses the played canon character's card instead.

Per-character hard limits

Start or load a chat world to list its cast.

Season kickoff

Starting a season always posts an opening frame plus a short “your move” card in the chat and focuses the input. Auto-kickoff additionally sends one player message on a fresh chat, which makes the narrator reply immediately. It is skipped when the chat already has story history.

World clock

A day passes every five turns by default. The top-bar time chip freezes and unfreezes time.

Pacing / scene director

A cut is always explicit and never moves the player. Frozen scenes offer Release time instead of a cut.

Off-screen world tick

One in-game day must pass first; rates come from data/agendas.json. A held scene (time frozen) pauses the tick.

Newspaper

With the feature on and the newspaper agent off, editions are built deterministically from events. A held scene publishes nothing.

Domain sensorium

The Domain tab and the block appear only when a season authors a domain block and plays as the villain. The domain follows the season, not the played identity.

Villain-victory epilogue

The epilogue is written once when the final deadline passes or the main threat reaches its terminal stage. The player then chooses Resistance, Join the villain, or End here.

Bad ends (opt-in)

Bad-end detection is opt-in. While disabled, no bad-end agent calls or state writes occur.

Agents: routing, prompts, and cadence

A blank prompt uses the built-in role prompt. A blank connection profile uses the main SillyTavern connection.

Map overlay and editor

The editor changes overrides, never the SVG art. Global edits export to data/map/overrides.json; per-chat edits (destroyed bridges, captured districts, virtual nodes) stay inside this chat's world state.

Data and this chat

Settings are global. The world, season, cast, and map overrides in the current chat are per-timeline. Resetting the world removes only this chat's world and its generated world book.

World export and import

A world bundle contains the WorldState, season definition, roster slice, player identity, and cast mode. Importing into another chat keeps the story but rebinds it to that chat; the generated world book is re-materialized on demand.
